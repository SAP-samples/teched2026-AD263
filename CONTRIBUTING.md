# Contributing

## How to Contribute

We welcome contributions from the community. Before submitting a pull request, please read the guidelines below.

## Issues

Use [GitHub Issues](../../issues) to report bugs or request improvements to the exercise materials.

## Pull Requests

1. Fork the repository
2. Create a branch: `git checkout -b fix/your-description`
3. Make your changes
4. Submit a pull request against the `main` branch

## Code of Conduct

This project follows the [SAP Open Source Code of Conduct](https://github.com/SAP/.github/blob/main/CODE_OF_CONDUCT.md).
